# Load Forecasting System (Java)

## Overview
This project predicts future load using historical data. It demonstrates basic data analysis and forecasting techniques.

## Features
- Average-based prediction
- Trend-based prediction
- Hybrid model (average + trend)

## Tech Stack
- Java

## How to Run

Compile:
javac src/Main.java

Run:
java -cp src Main

## Concept
Combines statistical and trend-based approaches to simulate real-world load forecasting systems.
